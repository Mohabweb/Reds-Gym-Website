# Reds Gym Website

A responsive website built for Reds Gym, a local gym in Alexandria, Egypt.

This project was created as a portfolio project to demonstrate a real-world website for a local business.

## Features

* Responsive design for mobile, tablet, and desktop
* Red and black visual style
* Gym information
* Membership plans and offers
* Image gallery
* Location information
* Contact information
* Social media links
* Mobile-friendly navigation
* Simple animations and interactions

## Purpose

The goal of the project was to create a simple website that gives visitors the main information they need about the gym in one place.

The website includes information about the gym, membership prices, offers, photos, location, and ways to get in touch.

## Responsive Design

The website is designed to work on different screen sizes, including:

* Mobile
* Tablet
* Desktop

## Deployment

The project can be deployed using platforms such as Vercel or Replit.
